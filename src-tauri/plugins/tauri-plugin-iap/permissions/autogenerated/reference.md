## Default Permission

capyroom 内购：拉商品 / 购买 / 恢复购买 / 读已有凭证。
四条都是"问苹果"，落账另走内核 reward_purchase。

#### This default permission set includes the following:

- `allow-products`
- `allow-purchase`
- `allow-restore`
- `allow-entitlements`
